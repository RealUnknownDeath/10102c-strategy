10102C / Override

2. General maneuvers

Reusable actions before the match-specific decisions.

Agreed actions; timing unmeasured · October 6, 2026 · Agreed direction plus clearly marked proposals

These are explanations of actions, not named match calls. Timings and physical reliability remain to be measured.

Separate scoring jobs

10102C normally handles R1 from below while Red-1 handles N2 from above. Use separate pickups and approaches so the pair keeps producing points. Goal allocation changes with access and ownership; it is not a command to keep feeding a lost area.

Recover space while scoring

When blue flips Left and leaves, use the next productive scoring path to re-establish zone control, then flip at a convenient opening. The objective is useful scoring plus control, not an empty chase.

Add a limited yellow burst

For a manageable projected deficit, one robot adds yellows while the other keeps useful color cycles, or both make a brief burst. Return to sustainable scoring when the projected gap is covered. Default yellow space is R1/N2; do not assume N2 can be cleared later.

Hand over coverage

The incoming robot establishes coverage before the outgoing robot leaves. State which robot answers Left and which answers Down. Swap based on position and capability rather than forcing names to match the drawing.

Establish the second defended area

When consistently outscored, Red-1 builds N2, optionally adds useful N1 color, then establishes Down. The stronger scorer retains Left responsibility while scoring the southern goals; the weaker Down holder scores locally only when safe. This transition must create enough controllable value to justify its cost.

Shorten the cycle and retreat

When a credible threat arrives, return to the assigned toggle approach. Do not send both robots to the same threat. The proposed lower-loader retreat needs practice: a shorter drawn line does not establish who arrives first.

Leave only with a safe response

Park or take useful open-toggle value only if they cannot punish the vacated zone in time, or we can reliably return or intercept. Parking generally has a shorter return path in our intended setup. If there is any risk to coverage or the winning margin, stay; productive local scoring can continue.

Remove an own-goal liability

If the relevant toggle is lost, a legal own-alliance-goal removal may reduce the opponent’s yellow value. R1/R2 are distinct from neutral N2/N4. Recount any red halves lost as well. This is a fallback, not the normal ending.
